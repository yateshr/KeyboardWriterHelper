# Grammar respects punctuation boundaries and settings.
"The files, is ready. " => "The files, is ready. "
"He will, goes home. " => "He will, goes home. "
@ punctuation off
"The files is," => "The files is,"
"The files is, " => "The files are, "
@ reset
@ phrases off
"The files is ready. " => "The files is ready. "
"He doesn't likes it. " => "He doesn't likes it. "
@ fix files is=files remain
"The files is ready. " => "The files remain ready. "
@ reset
